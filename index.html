// 核心能力

从打开到进游戏，
不用再切换五个工具

启动器负责把散落在各处的版本、依赖、账号与模组整理成一份清单。你要做的，只是选中版本然后点「启动游戏」。

01 / VERSION

版本与启动，
每一步都看得见

自动扫描 .minecraft/versions，也支持把任意位置的 versions 目录加进列表。启动前自动校验并补全 libraries / assets / natives，进度实时反馈，日志随时可查，还能一键终止游戏。

  • 版本重命名、删除、打开目录、自定义图标
  • 每个版本独立保存 Java、内存与附加启动参数
  • 可选「游戏启动后关闭启动器」

细节藏在边边角角

不只是「能启动」。Wiki、种子地图、基岩版、界面自定义，都被塞进了这个不到 30 MB 的窗口里。

01

Wiki 内置浏览器

正文不是 iframe，而是把真实的浏览器窗口用 SetParent 嵌进界面，因此不会被站点的 X-Frame-Options / Cloudflare 策略拦截，默认直接打开 zh.minecraft.wiki。

多面板拖拽调整大小拖出变独立窗口方块 / 合成 / 附魔 快捷入口
02

种子地图

输入种子、选好游戏版本与维度，直接用启动器窗口打开 Chunkbase 种子地图，也可以交给浏览器。

03

基岩版也能管

检测本地已安装的 Minecraft for Windows 并启动，支持 Store 渠道 / 镜像源下载安装包或安装本地包，还能直接打开存档目录。

04

侧边栏自己排

设置 → 个性化 → 管理侧边栏：点卡片开关板块，按住拖动调整顺序（设置固定保留），顺序写进 Setup.ini。

05

长得由你决定

主题色、自定义背景图与模糊度、默认板块、首页小组件、窗口圆角与自适应尺寸，窄窗口下设置页导航自动改为顶部横排。

06

收藏夹

模组 / 整合包 / 资源包 / 光影 / 数据包详情页一键收藏，下载页顶部直接回到详情页，点 × 取消。

提示找不到 Java？

在设置页或版本设置里指定 java 路径，或使用「下载 Java」。游戏版本要求的 Java 大版本不匹配时，启动器会给出提示。每次启动也会在后台全盘扫描系统 Java 并缓存结果。

单文件 exe 首次启动有点慢？

单文件模式每次启动都要解包到临时目录，属于正常现象。可用 MCHL_ONEDIR=1 生成文件夹版，启动更快，但需要整个文件夹一起分发。

杀毒软件报毒？

PyInstaller 打包的程序被误报较常见。可以添加到信任，或者用文件夹版自行打包。

数据都存在哪里？

启动器在自身所在目录创建 .minecraft（旧版 MCHL 目录会自动迁移）：版本、依赖库、资源、日志、设置 Setup.ini、收藏 favorites.json、首页小组件 home.json 都在这里。设置页「启动器 → 数据目录」可以直接打开。
